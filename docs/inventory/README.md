# Dosya karar kaydı

Başlangıç commit'i: `345afa3679193023bdcfea8908e81695130f18f0`. [Envanter](base-files.csv) o ağacın 8.848 dosyasını kapsar; bütün dosyaların insan tarafından içerik incelemesinin tamamlandığı anlamına gelmez.

[Dört kesin tekrar](exact-duplicates-removed.csv) aynı boyut ve aynı Git blob kimliğine sahip final/ çıktısı varken replay/ görünümünden çıkarıldı. Toplam 229,793,673 bayt çalışma ağacı tekrarı. Özgün sürüm, final tabloları ve bütün diğer olumsuz sonuçlar korundu.

Bu işlem Git geçmişinin saklama boyutunu küçülttü veya masaüstündeki araştırma klasöründe alan açtı demek değildir. Aynı blob Git içinde zaten paylaşılır. Ana araştırma klasörü değiştirilmedi. Geçmiş yeniden yazılmadı; eski özel tam yedek tutuldu.

Diğer büyük dosyalar sırf eski/olumsuz oldukları için silinmedi. Kod, protokol, kanıt, olumsuz bulgu ve özgün veri korunacak. Ortam, indirme artıkları, erişim sayfası kopyaları ve yedekler için içerik/geri kazanım incelemesi ayrı gerekir. Public açılış tamamlanmadı.
