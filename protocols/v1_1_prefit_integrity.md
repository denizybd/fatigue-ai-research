# Protocol amendment v1.1: pre-fit integrity fixes

2026-10-20, before any real-data model fitting/results. Independent conceptual code review found that a13-group minimum in v1 cannot leave4 fit groups after one test and9 calibration groups. Enforce at least14 total AND directly enforce at least4 fitting groups. This corrects a feasibility arithmetic inconsistency, not an outcome-driven exclusion.

Checkpoint resumption must validate input SHA256, source-code SHA256, seeds, split scheme and bootstrap count. Unsigned or mismatched checkpoints cannot be silently reused. Numerical stress monotonicity is measured on held-out feature locations with a fixed ±.01 log-amplitude perturbation and all other covariates fixed. Positive location slope is reported as a model limitation; no after-the-fact monotonic correction is applied.
