# Seven-source provenance and endpoint checks

Prepared20October2026 before v2 model fits. See seven_source_evidence.csv for one source per row. Full author-uploaded original texts were read for three sources; publisher section previews and immutable raw JSON were checked for the others. Access failures are retained, and abstracts are not promoted to methods verification. No contacts were made.

The strongest new correction is the microstrut stress-definition conflict: the original publisher section describes maximum stress, while the database stores the plotted numerical scale as amplitude despite positive R. Under the database interpretation every row implies a maximum stress substantially above the paper stated yield bound; unit_conflict.json records exact arithmetic. Exclude this curve from strict main analysis. A replacement by0.475times the database value would be an approximation because row-specific R is missing; it must not silently become measured ground truth.

The Cui pair is load/stress controlled, not strain controlled. Both original methods confirm this, and JMST explicitly says constant amplitude to total fracture. IJPlast directs the reader to the JMST work for material/testing details and the two4point curves agree within2.5percent in cycles and0.1percent in stress. Merge the family and use one representative as-built curve. This supports precautionary campaign grouping without proving specimen identity. JMST is the preferable curve representative because constant-amplitude and endpoint definitions are explicit.

Dastgerdi four curves have primary-text support: two orientations and two layer thicknesses, uniaxial load control at10Hz/R0.1, fracture endpoint. Spotchecks against stated157.5MPa and85.5MPa long-life examples support the amplitude scale. No physical specimen identifiers or independent-build mapping were recovered.

Shrestha database mode filtering is correct: only raw datasets1,3,5,7 are axial;0,2,4,6 are rotating-bending and absent from primary. This is a raw-metadata check, not original-caption verification. Kotzem intentional void curves require a separate population decision; databaseKt1 cannot certify the absence of artificial defects. Full source methods were not recovered for Kotzem, Shrestha or Wang/Su. A strict source-verified cohort must exclude or explicitly quarantine these unresolved entries; retaining them in a database-labelled sensitivity is permissible with a clear label.

Sources and exact sections are in the CSV. Author-uploaded papers were accessed through ResearchGate because institutional PDF downloads timed out or returned403. These are original full texts uploaded by authors, not ResearchGate model summaries. PDF figure visual checks were not completed. All downloaded publisher full texts remain copyrighted sources and should be omitted from shareable code packages.
